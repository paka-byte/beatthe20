# BEAT THE 20 · ยิงผ่าน 20 นายด่าน

เกมยิงประตูแนวการ์ตูน ให้ยิงผ่านผู้รักษาประตูพรีเมียร์ลีกทั้ง 20 ทีม
ด่านเรียงจากโกลที่เสียประตูเยอะสุดไปหาโกลที่เสียน้อยสุด (ด่าน 20 = บอส)
ยิงเข้าได้เฉพาะมุมที่โกลคนนั้นเคยเสียประตูจริงในฤดูกาลนี้ ข้อมูลจาก FotMob shotmap
ทุกลูกที่ยิงเข้า เกมจะเฉลยว่ามุมนี้ใครเคยยิงเข้า (ใช้รูปหน้าจาก FPL)

## ไฟล์ในโปรเจกต์
| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | ตัวเกมทั้งหมด (HTML/CSS/JS ไฟล์เดียว) |
| `data/keepers.json` | ข้อมูลจริง ได้จากการรันสคริปต์ ถ้ายังไม่มีไฟล์นี้ เกมจะเปิดในโหมดตัวอย่าง (ข้อมูลสุ่ม) |
| `scripts/fetch-data.mjs` | ดึงข้อมูลจาก FotMob + FPL มาสร้าง `data/keepers.json` |
| `netlify/functions/leaderboard.mjs` | API ของ leaderboard (`/api/leaderboard`) เก็บคะแนนใน Netlify Blobs |

## 1) ดึงข้อมูลจริง (รันบนเครื่องตัวเอง)
ต้องมี Node 18 ขึ้นไป
```bash
npm install
npm run fetch        # สร้าง data/keepers.json
```
- รันซ้ำได้ทุก GW แมตช์ที่ดึงแล้วถูกเก็บไว้ใน `.cache/` ไม่ต้องดึงใหม่
- ตอนรันจะมีสรุปรายทีมออกมาให้ดู ถ้ามีทีมไหนจับคู่ชื่อกับ FPL ไม่ได้ ให้ใส่ `TEAM_OVERRIDES` ในสคริปต์
- อยากเปลี่ยนโกลประจำทีม (ค่าเริ่มต้นคือคนที่ลงเล่นนาทีเยอะสุดใน FPL) ให้ใส่ `KEEPER_OVERRIDES`
- **เช็กทิศทางครั้งแรก:** เปิดเกมแล้วดูลูกที่คุณจำได้ เช่น ลูกที่เข้ามุมขวาบน ถ้าในเกมขึ้นกลับด้าน ให้เปิด `FLIP_X`, `FLIP_Y` หรือ `FLIP_LAT` ในสคริปต์ แล้วรันใหม่
- FotMob ไม่มี API ทางการ ถ้าเว็บเปลี่ยนโครงสร้างแล้วสคริปต์พัง ให้ดูฟังก์ชัน `loadFixtures` / `loadMatch` สคริปต์ค้นหาข้อมูลแบบกว้าง ๆ ไว้แล้ว เลยน่าจะทนการเปลี่ยนแปลงเล็ก ๆ ได้

## 2) Deploy ขึ้น Netlify
leaderboard ใช้ Netlify Function ซึ่ง**ใช้ไม่ได้ถ้า deploy แบบลากไฟล์วาง** ต้องใช้วิธีใดวิธีหนึ่งนี้
- **Git:** push โปรเจกต์ขึ้น GitHub แล้วกด Import ใน Netlify ไม่ต้องตั้งค่าอะไรเพิ่ม (`netlify.toml` ตั้งไว้ให้แล้ว)
- **CLI:** `npm i -g netlify-cli` → `netlify login` → `netlify deploy --prod`

Netlify Blobs เปิดให้อัตโนมัติ ไม่ต้องสร้างฐานข้อมูลเอง
ทดสอบในเครื่องพร้อม leaderboard ได้ด้วย `netlify dev`

## ปรับความยาก (ใน `index.html` ส่วน CONFIG)
- `SHOTS_PER_LEVEL` = 5 ลูกต่อด่าน
- `BOSS_ZONE_FROM` = 16 (ด่าน 1–15 ต้องเข้า 2 ลูก · ด่าน 16–20 ต้องเข้า 1 ลูก)
- `POOL_FRAC` = 0.7 (ทุกรอบสุ่มเทป 70% ของลูกที่เสียจริง กันคนจำคำตอบ)
- `CONTINUES` = 1 ชีวิตพิเศษต่อเกม · `TAPE_MULT` = 0.7 (แต้มหลังใช้ดูเทป)
- `HIT_RADIUS_M` = 0.9 เมตร (ยิงห่างจากจุดที่เคยเข้าจริงได้ไม่เกินนี้ถึงจะนับว่าเข้า ใส่ค่ามากขึ้นเกมจะง่ายขึ้น)

## โหมดเล่น
- **ปกติ:** เลือกจุดยิง (มุมกล้องเปลี่ยนตามจุด) แล้วจิ้มมุม ตรงกับมุมที่โกลเคยเสียจากจุดนั้นคือเข้า · leaderboard "วันนี้" + "ตลอดกาล"
- **💀 Hardcore:** สุ่มลูกจริงทีละลูก บอกทีม เท้า จังหวะ ระยะ xG ต้องยิงตรงลูกนั้น (รัศมี 0.9 + 0.8×xG เมตร) · leaderboard แยก
- **ตัวช่วย:** 📣 กองเชียร์หลังประตู (ซ้าย/กลาง/ขวา) · 👟 รองเท้าทองคำ (กรอบใหญ่ขึ้น 50%) · 📺 VAR (ฟรี) — เริ่มเกมมีอย่างละ 1
- **🎡 วงล้อ:** ยิงเข้า 3 ลูกขึ้นไปในด่าน ได้หมุนลุ้นตัวช่วย ชีวิตพิเศษ หรือแต้ม
- ค่าทั้งหมดปรับได้ใน CONFIG: `START_ITEMS`, `BOOTS_MULT`, `WHEEL_MIN_GOALS`, `HC_RADIUS_BASE`, `HC_RADIUS_XG`

## เสียง
ใส่ไฟล์ mp3 จริงในโฟลเดอร์ `sfx/` ดูรายชื่อไฟล์และแหล่งเสียงฟรีได้ใน `sfx/README.md`

## อัปเดตข้อมูลอัตโนมัติ (GitHub Actions)
ไฟล์ `.github/workflows/update-data.yml` จะรัน `fetch-data.mjs` ทุกอังคารและศุกร์ (09:17 เวลาไทย) แล้ว commit `data/keepers.json` กลับเข้า repo จากนั้น Netlify จะ deploy ใหม่ให้เอง
- ต้อง deploy ผ่าน GitHub (ข้อ 2 วิธี Git) ถึงจะทำงาน
- กดรันเองได้ที่แท็บ Actions → Update keeper data → Run workflow
- ถ้า FotMob บล็อกเครื่องของ GitHub (Action ขึ้นสีแดง) ให้รัน `npm run fetch` บนเครื่องตัวเองแล้ว push แทน

## กติกาการนับ
- จำนวน "เสีย" ใช้สกอร์จริงของทุกนัด จึงรวมประตูที่ทีมทำเข้าตัวเองด้วย และนับเป็นรายทีม (รวมนัดที่โกลสำรองลงเล่น)
- ลูกที่ยิงได้ในเกมไม่รวมการทำเข้าประตูตัวเอง เพราะไม่มีคนยิงให้เฉลย
- แต้มต่อลูก = 100 + (เลขด่าน × 10) + โบนัสลูกยาก (1 − xGOT) × 100 · ผ่านด่าน +200
